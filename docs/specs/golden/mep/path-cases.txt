# Shared zip-slip fixture (Fases 1 + 4 of the now-completed unit-test plan -
# see git history for docs/roadmap/plano-testes-unitarios.md). Consumed by
# both UI.Tests/Mep/MepZipValidatorTests.cs (C#, UI/Logic/MepZipValidator.cs)
# and scripts/core_unit_tests.cpp (C++, MepPack's own path normalization),
# so the format below must stay stable.
#
# Format: one case per line, TAB-separated: <path><TAB>ok|bad
#   - Blank lines and lines starting with '#' are ignored by consumers.
#   - "ok"  = a zip entry name that MUST be accepted (safe, no traversal/escape).
#   - "bad" = a zip entry name that MUST be rejected (zip-slip / path escape).
#   - Paths use '/' but a consumer must also normalize '\' to '/' before
#     checking, since a zip built on Windows may use either separator.
